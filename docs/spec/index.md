# リメイク版仕様

このセクションでは、今後作るTogoStanzaリメイク版仕様への入口を示す。

現行版調査の生メモはここに記録しない。それらは `docs/investigation/` に置く。

## 目的

このセクションには、新実装に関する判断を記録する。観測された旧挙動を採用するか、変更するか、延期するか、除外するかといった判断を扱う。

## 現在の状態

リメイク版仕様はまだ定義していない。

このセクションへの最初の入力は、完了した既存挙動調査から得る。
