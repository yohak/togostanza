# リメイク版仕様

ここでは、TogoStanzaリメイク版そのものの仕様を扱う。

現時点では、リメイク版の実装仕様はまだ確定していない。現行版調査をもとにした採用判断、互換性方針、再設計候補は [リメイク方針](./remake-policy.md) に記録する。

## この文書の位置づけ

最終的には、この文書を現行版とは切り離したリメイク版仕様書の入口として扱う。

リメイク版仕様では、次のような内容を扱う。

- リメイク版の公開API。
- CLIコマンドとオプション。
- stanzaリポジトリの入力構造。
- `build` / `serve` / `generate` / `init` の仕様。
- ランタイム生成物と埋め込み形式。
- Stanzaソースから利用できるAPI。
- 設定ファイルのスキーマ。
- migration noteから仕様へ取り込まれた確定事項。

## 現在の判断基準

現時点で判断基準として扱う文書は、次の通り。

- [プロジェクト憲章](../project-charter.md): プロジェクト全体の目的と互換性方針。
- [リメイク方針](./remake-policy.md): 現行版の挙動を維持、再設計、破棄する判断。
- [既存仕様メモ](../investigation/spec/index.md): 現行版で観測された挙動。
- [Follow-ups](../investigation/follow-ups.md): 後続調査、改善案、実装時判断の候補。

## 今後の整理方針

実装に入る段階で、[リメイク方針](./remake-policy.md) の採用判断をこの文書へ移し、現行版との比較ではなく、リメイク版単体の仕様として読める形に整理する。

その時点で、方針、移行メモ、観測メモは仕様本文から分離し、仕様本文にはリメイク版の外部契約だけを残す。
