# セットアップ

この文書では、ローカル準備に関する文書と読む順番を示す。

## 関連文書

- [リファレンス](./references.md): リファレンスを置くためのローカル領域。
- [サンドボックス](./sandbox.md): 仕様確認の試行錯誤に使うGit管理外領域。
- [検証領域](./workbench.md): CLI実行確認と比較に使う検証領域。
- [パッケージ配置](./package-layout.md): リメイク版パッケージの配置方針。
- [品質確認](./quality.md): リメイク版実装パッケージのformat、lint、type-check、testの入口。

## 読む順番

作業に応じて、次の順に読む。

1. リファレンスを準備する前に [リファレンス](./references.md) を読む。
2. 仕様確認の試行錯誤が必要になったら [サンドボックス](./sandbox.md) を読む。
3. 再現可能な比較に進む前に [検証領域](./workbench.md) を読む。
4. リメイク版実装に入る前に [パッケージ配置](./package-layout.md) を読む。
5. リメイク版実装パッケージの確認手順を扱う前に [品質確認](./quality.md) を読む。
