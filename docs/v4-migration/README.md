# V4 Migration

V3の調査、互換性判断、V4の実装と比較検証を行うための文書をまとめる。
V4移行作業を日本語で進めてきた開発経緯を踏まえ、このディレクトリの文書は、新規作成分も含めて日本語で維持する。
継続開発用文書への内容の整理・引き継ぎは、別の作業として扱う。配置変更によって既存文書の仕様や判断基準としての役割は変えない。
